Le jouet sous le foulard

6-9 moisattentionsans désordre5 min

Cachez son jouet préféré sous un foulard léger, attendez un peu, puis découvrez-le ou laissez bébé tirer le foulard.

Étapes

  1. Montrez le jouet et couvrez-le lentement du foulard : « Où est le jouet ? Il s’est caché. »

Encore 3 étapes dans l'application PlayMom

2 jeux gratuits, puis par abonnement avec une période d'essai

Ouvrir dans l'application

Ce qu'il vous faut

  • foulard léger
  • deux jouets de bébé

Sécurité

Le foulard couvre seulement le jouet, jamais le visage ni la tête de bébé.

Après le jeu, rangez le foulard : bébé ne joue pas avec sans vous.
