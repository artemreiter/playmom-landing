Ce qu'il vous faut

  • une table de salle à manger

Sécurité

C’est vous qui tenez la lampe à trappe vissée ; éclairez le sol, pas les yeux.

Tunnel uniquement sous une table stable, sans chaises ; les deux sorties ouvertes, rien à l’intérieur.
