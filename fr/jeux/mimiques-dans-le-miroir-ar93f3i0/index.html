Mimiques dans le miroir

6-9 moisémotionssans désordre6 min

Faites des grimaces à côté de bébé devant un miroir incassable et imitez-le, comme si vous étiez son reflet.

Étapes

  1. Montrez dans le miroir un visage surpris : « Oooh. » Puis un visage joyeux : « Youpi. »

Encore 3 étapes dans l'application PlayMom

2 jeux gratuits, puis par abonnement avec une période d'essai

Ouvrir dans l'application

Ce qu'il vous faut

  • miroir incassable pour bébé

Sécurité

Le miroir est incassable, aux bords lisses ; ne posez pas de miroir en verre par terre.

Si bébé se détourne ou devient grognon, arrêtez le jeu.
